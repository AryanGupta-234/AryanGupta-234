## engineering_principles

- **Clarity over hype** — describe what a project does today, not what it might become.
- **Security by design** — minimize collection, constrain capabilities and make sensitive actions explicit.
- **Evidence over assumptions** — distinguish measured behavior from estimates and research goals.
- **Maintainability** — readable documentation, reproducible setup and testable boundaries.
- **Continuous learning** — iterate, validate and improve in the open.
